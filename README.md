# FPP Help Navigator

WordPress-плагин «FPP Help Navigator» добавляет в админку пункт меню «Навигатор помощи ФПП» и регистрирует шорткод `[fpp_help_navigator]`.

## Структура плагина

Главный файл плагина находится в корне репозитория:

- `fpp-help-navigator.php` — WordPress plugin header, хуки активации/деактивации, регистрация меню и шорткода.
- `admin/` — заготовки административной части.
- `includes/` — заготовки классов плагина.
- `public/` — публичные статические файлы.
- `assets/` — CSS и JavaScript ассеты.
- `templates/` — шаблоны будущего интерфейса.
- `languages/` — файлы локализации.

## Установка

1. Скопируйте содержимое репозитория в каталог `wp-content/plugins/fpp-help-navigator/`.
2. В админке WordPress откройте раздел «Плагины».
3. Активируйте плагин «FPP Help Navigator».

## Использование

Разместите шорткод на странице или записи WordPress:

```text
[fpp_help_navigator]
```

В текущей версии шорткод выводит временный текст:

```text
Навигатор помощи ФПП подключён
```
